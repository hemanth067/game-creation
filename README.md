# BattleRoyale3D

A browser-based 3D battle-royale prototype built with JavaScript, Three.js, Socket.IO, and an Android WebView wrapper.

## Included
- Desktop/browser controls
- Mobile touch controls and landscape UI
- Inventory, weapons, loot, medkits, armor, ammo and grenades
- Training targets and shooting
- Node.js + Socket.IO server
- Android Studio/Gradle project targeting Android API 36
- GitHub Actions workflow for Android builds

See `ANDROID_PLAY_STORE.md` for Android/Play Store notes.
